# TigerLay Company Profile - React Assignment

Website company profile ini dibuat mengikuti referensi `FigmaVersiMobile.png` dengan tema gelap, aksen orange, hero phone mockup, section layanan, proses kerja, portfolio, testimonial, FAQ, contact form, dan footer.

## Tech Stack

- React
- TypeScript
- Vite
- TailwindCSS

## Fitur yang Sudah Dibuat

- Responsive mobile, tablet, dan desktop
- Header sticky dengan desktop navigation dan mobile hamburger menu
- Hero section dengan headline, CTA, metric cards, dan phone illustration
- About/result section dengan statistik bulat
- Process section interaktif menggunakan state React
- Service cards reusable dari data array
- Industry tabs interaktif
- Portfolio cards dengan visual mockup CSS
- Testimonial section
- FAQ accordion interaktif
- CTA banner dan contact form dengan validasi HTML
- Footer dengan link dan social buttons
- Struktur component-based, typed data, reusable props, dan styling TailwindCSS

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka URL yang muncul di terminal, biasanya `http://localhost:5173`.

## Build Production

```bash
npm run build
npm run preview
```
